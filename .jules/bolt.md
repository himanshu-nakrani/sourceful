## 2024-05-18 - [Optimize Analytics Queries]
**Learning:** `analytics_overview` endpoint fetched every single row from `users`, `documents`, `messages`, and `auth_sessions` into application memory just to perform date-filtered counts. This is an $O(N)$ memory and time complexity scaling problem, which is unacceptable for tables that grow indefinitely (e.g., messages and sessions).
**Action:** Push the time-based aggregation down to the database using `COUNT(*)` with `WHERE created_at >= ?` or `WHERE created_at >= NOW() - INTERVAL '...'`. SQLite and PostgreSQL expect dates formatted differently, so `settings.using_postgres` can be used to conditionally pass datetime object or ISO formatted strings.
